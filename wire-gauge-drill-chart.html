Drill Bit Conversion Chart — Wire Gauge · Metric · Standard

Every drill size from the number/letter wire-gauge series, the fractional-inch (standard) series, and the metric series, merged and sorted smallest → largest. A blank cell is a gap — that system has no size within tolerance of this row. The Relative size column lists the nearest smaller and larger bit in each system so you can see at a glance which bit you have is closest to the one you need.

How to read the Relative-size bars

a smaller bit −25%
this row's size reference
a larger bit +10%
  • The dashed line marks this row's diameter — your reference.
  • A bar's length is its diameter: shorter bars stop left of the line (smaller), longer bars cross it (larger).
  • The farther a bar is from the line, the bigger the size difference — the ±% states it exactly.
  • The underlined bar is the bit this row actually is; its color shows the system.
